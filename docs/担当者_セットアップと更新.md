# 担当者向け：新しい PC のセットアップと更新

一般職員には **[職員用_開き方.txt](./職員用_開き方.txt)** だけ渡してください。

---

## 新しい PC を1台追加するとき（チェックリスト）

- [ ] **Node.js LTS** をインストール（https://nodejs.org/）
- [ ] アプリフォルダを置く（Git clone または ZIP 展開）
- [ ] **`.env.local`** をフォルダ直下にコピー（秘密・各 PC 同じ Supabase でよい）
- [ ] 職員 PC では推奨設定（PIN ログイン）:
  ```env
  ALLOW_PIN_LOGIN_BYPASS=false
  ```
  （`DEV_AUTO_LOGIN_*` は書かない）
- [ ] 一度 **`launch-app.bat`** または `npm install` 済みにする（初回のみ数分）
- [ ] デスクトップにショートカット作成 → 下記「ショートカット」を参照
- [ ] ブラウザでログインできることを確認（一般用・6桁 PIN）
- [ ] 職員用紙1枚を印刷し、担当者連絡先を記入

---

## ショートカットの作り方（職員用）

**おすすめ:** デスクトップに「医療機器管理を起動」

1. エクスプローラでプロジェクトフォルダを開く
2. **`医療機器管理を起動.vbs`** を右クリック → **ショートカットの作成**
3. ショートカットをデスクトップへ移動
4. 名前を **医療機器管理を起動** に変更

または PowerShell（プロジェクトフォルダで）:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\create-desktop-shortcut.ps1
```

**職員に渡さないもの:** `キャッシュクリアして起動.bat`、`.env.local.example`、開発者向け README

## アプリを更新するとき（年数回）

開発 PC で GitHub に push 済みの内容を、利用 PC に反映します。

各利用 PC（または担当者が回る）で:

1. アプリを止める（黒い起動画面を閉じる）
2. プロジェクトフォルダで:
   ```powershell
   git pull
   ```
3. 依存関係が変わっている場合のみ:
   ```powershell
   npm install
   ```
4. **`医療機器管理を起動`** で再起動
5. 問題があれば **`キャッシュクリアして起動.bat`**（担当者のみ）

**データベース変更**（新しい SQL があるとき）:  
Supabase SQL Editor で migration を **1回だけ**実行（全 PC 共通）。

**職員への連絡例:** 「明日から画面が少し変わります。いつもどおりショートカットから開いて PIN で入ってください。」

## 管理者 PC と職員 PC の設定差（推奨）

| PC の種類 | ALLOW_PIN_LOGIN_BYPASS | DEV_AUTO_LOGIN_* |
|-----------|------------------------|------------------|
| 職員用 | `false`（PIN 必須） | なし |
| 開発・管理者用 | 省略可（開発省略ログイン） | 省略可 |

## トラブル（担当者向け）

| 症状 | 対処 |
|------|------|
| Node.js がない | LTS をインストール |
| .env.local がない | 管理者 PC から安全にコピー |
| 真っ白・古い画面 | `キャッシュクリアして起動.bat` |
| git なし | ZIP で上書き配布（`node_modules` は除く） |
